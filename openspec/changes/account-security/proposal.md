# 单管理员账户安全

## Why

Tattoo 当前只能通过部署工具重置管理员密码，没有网页改密、双重验证或退出其他会话入口。个人自托管实例需要在日常浏览器操作中管理账户安全，并在验证器丢失时保留明确恢复路径。

## What Changes

- 保留一个管理员和关闭公开注册的产品边界，增加“账户安全”页面。
- 增加原密码验证后的修改密码与退出其他会话。
- 增加可选 TOTP 双重验证、受会话约束的绑定确认和两阶段登录，兼容 Google Authenticator 与 Microsoft Authenticator 的通用验证码方式。
- 增加一次性恢复码的首次展示、重新生成与消费，避免正常读取接口泄露恢复材料。
- 将密码、因子、会话、登录挑战和备份恢复规则纳入统一的事务与撤销规则。

## Capabilities

### New Capabilities

- `account-security`：单管理员凭据更新、TOTP、恢复码、会话撤销及部署恢复边界。

### Modified Capabilities

无独立历史 OpenSpec capability 需要替换；本项扩展现有 Identity 行为并由 [SPEC 第 15 节](../../../docs/SPEC.md#15-单管理员账户安全2026-11-28已确认) 引用，既有登录、CSRF、会话恢复与未保存保护仍有效。

## Impact

涉及身份模块、共享契约、用户与会话相关数据库迁移、登录及账户安全界面、重置与备份恢复工具和对应测试。验证器不依赖 Google 或 Microsoft 云登录，也不引入短信、邮件、Passkey、多用户、角色管理或新的远程服务。

界面、PostgreSQL 并发与完整应用验收分别记录；标准向量及二维码配置验证不冒充真实手机 App 扫码验收，源码完成不自动表示镜像已发布。
