# 工作台改版设计

## 目标与边界

沿用现有业务状态和接口，替换 UI 基础层并改善布局。管理页参考 Twenty 的紧凑导航和清楚的信息层级；编辑页参考 AFFiNE 的专注正文体验。保留 Tattoo 的绿色强调色、中文文案和 Phosphor 图标体系，避免加入与个人创作无关的装饰、虚假统计或未实现入口。

## 技术决策

### 组件与样式

- 使用项目内维护的 shadcn/ui 组件与 Radix 可访问交互原语，配合 Tailwind 的语义颜色变量；保留 React 19 和 Tiptap 3。
- 移除 Ant Design 控件与依赖，不保留两套全局主题。可提供薄的应用控件封装，集中处理加载、错误和业务常用参数；封装不得替代真实的 shadcn/ui 基础组件或重新实现一套通用表单框架。
- 表单使用可访问的原生表单与受控值，保留已有必填、邮箱、URL、长度校验和待处理禁用逻辑。不得把既有密钥回填到输入框。
- 用语义变量统一画布、面板、文字、边框、悬停、选中和成功/警告/错误状态。状态始终同时有文字，普通文字、控件边界与焦点应在两套主题中可辨认。

### 外观选择

- 偏好值为 `light`、`dark`、`system`，默认 `system`；最终主题从用户偏好与 `prefers-color-scheme` 推导。
- 当前浏览器的偏好写入本地存储；只保存外观选择，不新增服务器设置或数据库字段。存储不可用或值无效时继续以系统主题打开，不能阻断登录或编辑。
- `system` 模式监听系统主题变化；显式浅色/深色不随系统变化。切换主题不得卸载当前文章或重置表单、光标和未保存状态。
- 在应用挂载和首次样式绘制前，由同源外部初始化脚本设置根元素主题与 `color-scheme`；沿用现有 `script-src 'self'`，不为主题放宽 CSP 或加入内联脚本例外。
- 登录页和已登录页面都可选择外观，菜单用清楚的“浅色 / 深色 / 跟随系统”文案，当前选择可见。

### 导航与管理页

- 桌面使用清楚的工作区导航，当前位置有文字和选中状态；移动端收拢导航，展开后可用键盘、关闭按钮和返回操作离开。
- 页面标题、说明、主操作和次操作分层；列表、任务状态和分页紧凑但保留足够点击区域。长标题、错误和 URL 在窄屏换行，不遮挡操作。
- 表单标签与控件绑定，错误就近显示；失败后保留用户输入并提供明确恢复方式。加载时告知正在处理，不将空数据和加载失败混为一谈。
- 所有可点击动作有实际实现；异步提交期间限制重复提交。迁移不增加自动搜索、自动付费生成或自动投递。

### 专注编辑

- 正文使用受控阅读宽度和足够行高，标题、正文工具栏与保存操作形成清楚层级；文章信息在窄屏可收拢而仍可找到。
- 保存仍是显式操作，展示未保存、保存中、已保存修订和冲突/失败。提供 Ctrl/Cmd+S，与保存按钮共用有效性检查，弹窗或受限状态下不得意外触发保存。
- 继续保留标题、作者、摘要、来源、封面、格式、上传、历史、预览、AI 候选采纳和投递入口。摘要超限仍可本地保存，投递前明确限制。
- 微信预览是近似排版检查，隔离 iframe 与阅读画布保持明确白底、深色正文；外围弹窗跟随主题。工作台切换不重写文章、生成结果或导出样式，不承诺与所有微信客户端显示完全一致。

### 可访问性与状态保护

- 弹窗具备可访问标题，打开后焦点进入其中，Tab 不泄露到背景，关闭后尽量返回触发位置。关闭、提交、加载和禁用状态不只依赖图标。
- 保留离开页面和退出时的未保存提醒；会话过期时保留挂载的编辑内容，重新登录后可以继续保存。
- 保留已保存修订绑定、目标账号、远程写入开关、明确确认和不确定结果核对，不能因为简化界面绕过这些条件。
- 尊重减少动态效果偏好，动效仅用于清楚表达状态；不引入打断写作的背景动画或跳动布局。

## 迁移顺序

先接入组件和语义主题变量，建立主题初始化与外观选择；再迁移导航、管理页、表单和编辑页，最后移除 Ant Design 和旧专属样式，调整相关浏览器选择器。业务状态机和接口保持由现有模块负责，避免在视觉改版中重写。

## 验证

1. TypeScript、生产构建、格式与已有单元检查。
2. 离线 Playwright API fixtures：三种外观、刷新记忆、系统变化、存储失败、桌面/窄屏、导航、表单、弹窗键盘操作、编辑与快捷保存、会话恢复及投递条件。
3. 既有浏览器流程：登录、账号、文章修订与摘要边界、AI、资料、主题创作和投递；组件库专属 CSS 选择器改成语义定位。
4. 检查浅色、深色、移动端的实际截图，确认无页面横向溢出、不可读字段和被遮挡操作。

本地缺少数据库或 Docker 时，明确记录未执行的后端集成/部署验收；离线 fixtures 不可宣称真实模型、Tavily、微信或新镜像发布已通过。
