# 开始使用

[文档首页](README.md) · [部署指南](DEPLOYMENT.md) · [模型配置](MODELS.md) · [常见问题](FAQ.md)

登录后，可以先手写一篇文章，也可以配置模型后从主题生成图文。微信接入可以稍后完成；本地写作不要求先提供 AppID/AppSecret。

## 1. 先保存一篇自己的文章

在“内容”点击“新建文章”，填写标题、摘要和正文，可上传封面及正文图片，再点击保存。

保存会生成可回看的修订。后续编辑再保存会形成新修订，历史正文和图片仍按原修订保留。切页或关闭浏览器前先保存，未保存的编辑不在备份中。

需要处理已有文章时，在“内容”中打开它继续编辑即可。此时不必配置模型或公众号。

## 2. 配置文本和图片模型

进入“模型配置”，分别保存两项配置：

| 配置     | 需要填写                                                                                  |
| -------- | ----------------------------------------------------------------------------------------- |
| 文本模型 | Chat Completions、Responses 或 Anthropic Messages 协议，服务 Base URL、模型 ID 和 API Key |
| 图片模型 | 支持 Images Generations 的服务 Base URL、模型 ID 和 API Key；按服务要求选择尺寸及返回格式 |

两项可以使用不同服务商。服务地址填写 Base URL，包含服务需要的版本路径，不填写完整生成端点；例如应用会为 Chat Completions 自动追加 `/chat/completions`。图片模型使用独立的 `/images/generations`，文本协议选择不会改变图片接口。

密钥只在自己的页面输入，由后端加密保存，读取时不返回原值。分别执行“实际生成验证”，确认文本和图片服务都可用；验证会真实调用服务，可能产生费用。

地址、协议、图片参数及 Docker 网络说明见[模型配置与 AI 创作](MODELS.md)。

## 3. 从主题生成图文

回到“内容”，点击“主题创作”，输入主题并明确开始：

1. 后台生成文章标题、摘要和正文。
2. 根据实际文章内容生成封面。
3. 全部完成后自动保存为一篇可编辑的新稿。
4. 点击“打开成稿编辑”，审阅内容并继续编辑。

不需要先添加资料或单独填写封面提示词，主题创作也不会自动联网搜索。任务保存在后台，切页或刷新后可从主题创作记录找回；它不会覆盖你正在编辑的另一篇文章。

封面生成失败时，文章候选会保留，可选择“仅重新生成封面”，不必重新生成文章。如果文章和封面已成功、仅最终保存中断，使用“完成保存”直接保存已有结果，不再次调用模型。遇到“结果待核对”先检查任务和服务商记录，再决定下一步，系统不自动重发收费调用。

需要指定参考内容时，可在“资料”采集公开链接、手动拉取 RSS/Atom，或配置 Tavily 后按需搜索；随后在编辑器的 AI 写文章入口选择资料。操作见[资料获取](SOURCES.md)。

## 4. 编辑、保存并预览

检查生成内容的事实、来源、表述与封面，再按自己的需要修改。编辑器还支持单项 AI 写作、改写、封面和插图生成，这些结果先展示候选，需明确采用，再保存为修订。

保存后查看微信排版预览，并按页面提示处理缺失封面、图片或内容限制。投递绑定的是选定的已保存修订，排队后的继续编辑不会改变这次投递内容。

## 5. 接入微信公众号

如果暂时只写作，可停在这一步之前。需要存入微信草稿时：

1. 在“公众号账号”添加账号，输入自己的 AppID/AppSecret。
2. 在微信侧配置调用 API 所用的出站公网 IP 白名单。
3. 在 Tattoo 执行“只读验证”，查看 token 和草稿读取结果。

只读验证不上传图片、不创建草稿，读取成功也不代表账号具备新增草稿权限。`40164` 等白名单问题见[微信接入与家宽出口](OPERATIONS.md#微信接入与家宽出口)。

准备明确创建草稿时，由部署管理员在 `.env` 启用 `REMOTE_WRITES_ENABLED=true` 并重新创建 API 和 Worker，步骤见[启用微信草稿写入](OPERATIONS.md#启用微信草稿写入)。该开关只控制微信写入，不控制 AI 或 Tavily 调用。

## 6. 明确存入草稿并核对结果

打开已保存文章，点击“存入微信草稿”，选择公众号，核对修订和预览，勾选确认后提交。

在文章投递详情或“投递记录”查看进度与结果，再到微信后台检查草稿。当前接入只创建微信官方草稿，不直接发表或群发；AI 生成和保存文章也不会自动投递。

若提交后连接中断，先获取原任务结果。出现“结果待核对”时，先按[待核对任务的处理](OPERATIONS.md#处理结果待核对的任务)检查微信后台，不通过重复提交猜测是否成功。

部署后的日常维护、升级和备份见[运行维护](OPERATIONS.md)。知乎与小红书内容导出尚未实现，当前也不提供自动选题或周期发布。
