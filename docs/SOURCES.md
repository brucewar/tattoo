# 资料获取与 AI 参考

登录后进入“资料”。可以采集公开链接、订阅 RSS/Atom，或使用 Tavily 搜索后选择原文。资料独立保存，不自动生成文章或创建微信草稿。

## 链接与 RSS

输入文章链接并明确采集。任务在后台读取标题和正文，详情保留来源、实际跳转地址、获取时间和可获得的发布时间。再次采集同一规范化 URL 更新原资料，不增加副本；不同地址不会因页面自报 canonical 被自动合并。

添加 RSS/Atom 地址后手动拉取，每次最多处理 20 条。订阅提供的文字可能仅为摘要，页面会明确标识，可进一步提取条目全文。拉取不会自动抓取所有条目链接，已有网页全文也不会被订阅摘要覆盖。取消订阅保留已保存资料及来源记录。本期不定时拉取，不自动评分或生成日报。

## Tavily 搜索

在资料页配置 Tavily Base URL（默认 `https://api.tavily.com`）和 API Key。只在自己的页面填写密钥；保存后后端加密，读取不返回原文。留空保留已保存密钥，需要清除时明确勾选。更换服务来源需输入新密钥或清除旧密钥，执行中的搜索暂不能修改配置。

保存配置不调用服务。填写查询并明确搜索时才调用 Tavily，可能产生费用。首批固定 basic、关闭 `auto_parameters`，最多取 5 个候选，不调用 Extract/Crawl 等接口。具体参数依据见 [调研记录](SOURCES-RESEARCH.md)。

搜索返回的是候选片段。明确选择采集后才抓原网页并保存正文；付费墙、需要登录或主要依赖浏览器脚本的页面可能无法提取，失败会显示原因，不用搜索片段伪装成全文。

## 选入 AI 写文章

在编辑器打开“AI 写文章”，选择最多 5 份已保存且有文字的资料，可与手填参考并用。总参考最多 80000 字符，超限会拒绝创建生成任务，不静默截短。RSS 文字仍标为可能仅摘要。

后端把实际文字和来源元数据固化到生成记录，后续刷新资料不修改已经提交的任务。候选仍需明确采用、人工核对并保存为文章修订；不自动插入引用，也不自动投递公众号。

## 获取边界与失败处理

- 仅获取公开 HTTP 80 / HTTPS 443 的 HTML、纯文字或订阅内容；私网、环回、保留及元数据地址不可抓取。每一跳重新检查 DNS 并绑定连接地址，最多 3 次跳转。
- 下载总时限 20 秒，压缩前后最多 2 MiB；单份文字最多 50000 字符。解析不执行脚本、不加载子资源，不抓图片、视频或任意附件。XML 拒绝 DTD 与自定义实体。
- 任务、来源和错误可在页面找回。创建响应丢失时获取原请求，不重新收费；浏览器无法保存待确认标识时不发出搜索。明确重新获取才建立新请求，不自动重试。
- `REMOTE_WRITES_ENABLED` 仍只控制微信写入，不关闭用户明确发起的搜索或 AI 调用。

Docker 升级会应用资料迁移，保留原主密钥。备份含资料、订阅、搜索配置及任务；恢复检查搜索密钥并冻结旧排队/执行中任务。步骤见 [运维说明](OPERATIONS.md)。模拟验证与真实 Tavily、模型服务验收分别记录。
