# 0.1.0 候选版本说明

更新：2026-11-24。代码与验证范围见 [P5](P5-VERIFICATION.md)、[P6–P8](P6-P8-VERIFICATION.md)、[文本协议](AI-PROTOCOLS-VERIFICATION.md) 和 [P9 资料获取验证](P9-VERIFICATION.md)。本次为可部署候选版本，真实 Tavily、模型及微信公众号验收单独保留；不代表完整产品全部完成。

## 本轮资料获取

- 新增“资料”页面：公开链接正文、RSS/Atom 手动拉取、Tavily basic 搜索及选择结果后采集。
- 资料按规范化 URL 去重，保留来源、正文与时间；RSS 文字明确标为可能摘要，取消订阅保留资料。
- AI 写文章可选已保存资料；生成任务固化实际正文和来源快照，后续刷新不改历史输入。
- 受限网络读取、持久任务、收费请求去重与恢复隔离；备份覆盖搜索密钥、资料、订阅和任务。操作见 [资料说明](SOURCES.md)。

## 本轮新增 AI 创作

- “模型配置”页面分别设置文本和图片模型；文本支持 Chat Completions、Responses、Anthropic Messages，图片保持独立接口。旧文本配置保留 Chat Completions，历史生成任务保留协议快照；密钥加密、脱敏，跨来源更换需明确处理旧密钥。
- 编辑器提供文章生成、整篇/选中文字改写、封面和正文插图，先预览并采用再保存修订。
- 独立持久生成任务、请求去重、断线刷新找回、明确重试与旧任务隔离；模型生成不会自动投递微信。
- 备份恢复覆盖模型密钥和旧生成任务。配置与操作见 [模型说明](MODELS.md)，自动检查与真实调用的区别见本轮验证记录。

## 已交付

- 管理员登录、会话及密码恢复；多个公众号账号的加密凭证、只读验证和显式测试草稿。
- 文章编辑、正文与封面图片、不可变修订、保存冲突保护、历史查看和微信预览。
- 确认账号与已保存修订后的后台草稿投递，素材映射隔离、唯一意图、执行记录、显式重试及未知结果人工核对。
- 标准 Docker/Compose 四服务部署，停机一致备份与空实例恢复；主密钥独立保管，恢复后禁用远程写入、撤销旧会话并隔离旧任务。
- 运维、升级回滚及 AT-01 至 AT-09 验收记录方式。

## P5 基线的历史验证范围

114 项单元、43 项真实 PostgreSQL 集成、14 项浏览器、生产构建及 Linux/amd64 Docker 镜像、四服务、持久化与备份恢复检查通过。具体命令、环境、CI 链接和本地执行限制见验证记录。部署不依赖指定 NAS 品牌或型号；未测镜像平台不宣称通过。

## 使用与限制

从 [README](../README.md) 开始部署，停机备份、对应版本镜像与主密钥保管、恢复后核对等步骤见 [运维说明](OPERATIONS.md)。默认关闭远程写入；首次真实测试由用户在自己的环境明确开启和发起，凭证只输入本机页面。

首版恢复要求 PostgreSQL 16、备份对应的精确应用镜像及原主密钥，只接受空目标，不提供强制覆盖或跨 CPU 架构恢复保证。暂不自动清理远程草稿/素材或本地未引用文件；只有明确保存的修订可恢复，关闭页面前未保存的编辑不在备份中。

知乎内容导出与小红书文案/图片导出仍为已确认的 P10 后续目标，尚未实现。资料获取首批为手动操作，热点榜、日报、自动选题和周期生成不在本轮。AI 创作的实现与限制见本轮新增说明，不以服务配置已保存代替真实生成已验证。

## 仍需完成

用户按 [真实微信验收](ACCEPTANCE.md#at-09-真实微信验收) 完成目标账号的测试草稿及普通图文草稿，记录接口结果与微信后台实际显示。模拟接口、人工确认或读取草稿成功均不替代该项。
