# 版本说明

## 0.1.0-rc.1 · 2026-11-24

首个提供 GHCR 镜像的候选版本，面向个人与 NAS 自托管。已完成主题到成稿、编辑修订和微信草稿的本地模拟闭环；真实模型、Tavily 与目标微信公众号仍需在自己的环境验证。

### 创作与资料

- **输入主题生成图文**：自动生成文章与封面，并保存为可编辑的新稿；持久任务支持刷新找回，封面失败可单独补做。
- **编辑与修订**：富文本正文、图片上传、封面、明确保存形成独立修订、冲突保护、历史查看与微信排版预览。
- **AI 助手**：写文章、整篇或选中文字改写、封面与插图；编辑器内先预览候选，再选择采用。
- **模型接入**：文本支持 Chat Completions、Responses、Anthropic Messages；图片使用独立的 Images Generations 兼容接口，允许不同服务配置。
- **资料库**：提取公开链接正文，手动拉取 RSS / Atom，Tavily basic 搜索后选择采集；写作可选已保存资料，历史任务保留实际输入快照。

### 微信草稿

- 支持多个公众号账号的加密凭证、只读验证与显式测试草稿。
- 确认目标账号和已保存修订后，由后台任务投递草稿，保留执行记录。
- 对不确定的远程结果保留人工核对入口，避免盲目重试造成重复草稿；正式发表在公众号后台完成。

### 部署与维护

- 公开镜像：`ghcr.io/brucewar/tattoo:0.1.0-rc.1`，支持匿名拉取，当前平台为 **`linux/amd64`**。
- 前端与 API 合并，API 和 Worker 共用一个 Tattoo 应用镜像；Compose 运行 API、Worker 与 PostgreSQL 三个容器。
- 默认部署只拉取固定版本镜像，宿主机无需 Node.js 或源码；源码构建使用单独的 Compose 覆盖文件。
- 提供随机初始配置、管理员密码恢复、升级指引、停机一致备份和空实例恢复。
- 恢复后禁用远程写入、撤销旧会话并隔离旧任务。现有备份恢复工具需要在管理电脑准备 Node.js 22 与匹配源码，详见[工具准备](OPERATIONS.md#准备备份恢复管理工具)。

### 升级与已知限制

升级前保留数据库与图片备份、原主密钥、Compose 文件和匹配镜像。从旧四服务部署升级需使用 `--remove-orphans` 清理旧 Web 容器，具体见[升级与回滚](OPERATIONS.md#升级与回滚)。数据库迁移后，仅改回旧镜像标签不保证可以回滚。

- 一个管理员、PostgreSQL 持久任务表、单 Worker；当前没有 ARM 镜像。
- 主题创作使用已配置模型，不自动搜索资料；AI 与 Tavily 调用可能产生服务费用。
- 知乎内容导出、小红书文案与图片导出尚未实现。自动选题、周期生成、热点日报与多平台自动发表未包含在此版本。
- 首版恢复只接受空目标，要求 PostgreSQL 16、精确匹配的应用镜像和原主密钥，不保证跨 CPU 架构恢复。
- 未保存的编辑不在备份中；暂不自动清理远程草稿、素材或本地未引用文件。
