# 0.1.0 候选版本说明

日期：2026-11-20。代码版本与 CI 结果见 [P5 验证记录](P5-VERIFICATION.md)。本次为可部署候选版本，真实微信公众号验收未执行；不代表第一阶段全部验收完成。

## 已交付

- 管理员登录、会话及密码恢复；多个公众号账号的加密凭证、只读验证和显式测试草稿。
- 文章编辑、正文与封面图片、不可变修订、保存冲突保护、历史查看和微信预览。
- 确认账号与已保存修订后的后台草稿投递，素材映射隔离、唯一意图、执行记录、显式重试及未知结果人工核对。
- 标准 Docker/Compose 四服务部署，停机一致备份与空实例恢复；主密钥独立保管，恢复后禁用远程写入、撤销旧会话并隔离旧任务。
- 运维、升级回滚及 AT-01 至 AT-09 验收记录方式。

## 已验证范围

114 项单元、43 项真实 PostgreSQL 集成、14 项浏览器、生产构建及 Linux/amd64 Docker 镜像、四服务、持久化与备份恢复检查通过。具体命令、环境、CI 链接和本地执行限制见验证记录。部署不依赖指定 NAS 品牌或型号；未测镜像平台不宣称通过。

## 使用与限制

从 [README](../README.md) 开始部署，停机备份、对应版本镜像与主密钥保管、恢复后核对等步骤见 [运维说明](OPERATIONS.md)。默认关闭远程写入；首次真实测试由用户在自己的环境明确开启和发起，凭证只输入本机页面。

首版恢复要求 PostgreSQL 16、备份对应的精确应用镜像及原主密钥，只接受空目标，不提供强制覆盖或跨 CPU 架构恢复保证。暂不自动清理远程草稿/素材或本地未引用文件；只有明确保存的修订可恢复，关闭页面前未保存的编辑不在备份中。

资料获取（RSS、搜索、指定链接）、AI 写作/改写/配图、知乎内容导出与小红书文案/图片导出仍为已确认的后续目标，尚未实现。

## 仍需完成

用户按 [真实微信验收](ACCEPTANCE.md#at-09-真实微信验收) 完成目标账号的测试草稿及普通图文草稿，记录接口结果与微信后台实际显示。模拟接口、人工确认或读取草稿成功均不替代该项。
