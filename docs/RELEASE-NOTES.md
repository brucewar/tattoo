## 0.1.0-rc.2 · 2026-11-28

本候选版本合并工作台改版与单管理员账户安全，镜像引用为 `ghcr.io/brucewar/tattoo:0.1.0-rc.2`。本地 `linux/amd64` 生产镜像构建、基础部署、完整备份恢复，以及镜像内账户安全、三种外观与字体加载检查已通过。实际 CI、GHCR 发布与拉取结果、源码提交和准确 digest 见[对应标签流水线](https://github.com/brucewar/tattoo/actions?query=branch%3Av0.1.0-rc.2)；RC 不更新 `latest`。

### 单管理员账户安全

- 增加账户安全页面：验证当前凭据后修改密码、退出其他会话，当前浏览器保持登录。
- 增加 Google/Microsoft 验证器兼容的 TOTP 绑定及两阶段登录，持久限制挑战与因子失败次数、拒绝重复时间步。
- 增加一次展示的恢复码、单次消费与重新生成；正常状态不返回密钥或恢复码明文。
- 普通部署密码重置保留已启用因子，显式应急重置才移除；备份恢复废弃旧会话、挑战、待绑定和恢复码，保留验证器。

范围由 [OpenSpec 账户安全](../openspec/changes/account-security/proposal.md) 管理，使用说明见[账户安全](ACCOUNT-SECURITY.md)，实际检查见[P14 验证记录](P14-VERIFICATION.md)。固定 `0.1.0-rc.1` 保持原产物，不包含本项功能。

### 工作台改版

- 使用项目内维护的 shadcn/ui 与 Radix 组件替换 Ant Design，管理页采用紧凑导航、列表和配置表单。
- 增加浅色、深色和跟随系统，记住当前浏览器的选择；首屏初始化、系统变化及切换均保留编辑状态。
- 编辑器增加可收起的文章信息、专注写作和清楚的保存状态；长标题支持换行，保留明确保存与 Ctrl/Cmd+S。
- 调整移动导航、错误重载、字段错误关联、弹窗键盘焦点和状态反馈，微信预览保留独立浅色画布。

本次变更按 [OpenSpec 提案](../openspec/changes/redesign-workspace/proposal.md) 管理；实现和未执行的检查见 [P13 验证记录](P13-VERIFICATION.md)。固定版本 `0.1.0-rc.1` 保持原产物，不包含本次改版。

### 从 rc.1 升级

升级前完成一致备份，保留原配置和 `APP_ENCRYPTION_KEY`，同时更新 API 与 Worker 的镜像。已有单管理员继续使用原密码登录，双重验证默认关闭，由管理员主动绑定。启动会执行数据库迁移，迁移后不能仅切回旧镜像代替回滚；需要回退时使用与旧版本匹配的完整备份和工具。具体步骤见[升级与固定镜像](DEPLOYMENT.md#升级与固定镜像)和[运行维护](OPERATIONS.md)。

## 开发分支修正 · 2026-11-26

- AI 文章生成在提示词中明确微信公众号摘要建议长度与 120 字符上限，生成结果按同一规则检查，覆盖三种文本协议及主题创作。
- 编辑器提前显示摘要长度和超限提示；较长的手写稿和历史稿仍可保存，不静默截断内容，不自动重试收费请求。

此修正通过 CI 后随 `edge` 和固定提交镜像发布；`0.1.0-rc.1` 镜像保持原产物。已有 NAS 部署需明确更新 API 与 Worker 使用的镜像。

## 0.1.0-rc.1 · 2026-11-24

首个提供 GHCR 镜像的候选版本，面向个人与 NAS 自托管。已完成主题到成稿、编辑修订和微信草稿的本地模拟闭环；真实模型、Tavily 与目标微信公众号仍需在自己的环境验证。

### 创作与资料

- **输入主题生成图文**：自动生成文章与封面，并保存为可编辑的新稿；持久任务支持刷新找回，封面失败可单独补做。
- **编辑与修订**：富文本正文、图片上传、封面、明确保存形成独立修订、冲突保护、历史查看与微信排版预览。
- **AI 助手**：写文章、整篇或选中文字改写、封面与插图；编辑器内先预览候选，再选择采用。
- **模型接入**：文本支持 Chat Completions、Responses、Anthropic Messages；图片使用独立的 Images Generations 兼容接口，允许不同服务配置。
- **资料库**：提取公开链接正文，手动拉取 RSS / Atom，Tavily basic 搜索后选择采集；写作可选已保存资料，历史任务保留实际输入快照。

### 微信草稿

- 支持多个公众号账号的加密凭证、只读验证与显式测试草稿。
- 确认目标账号和已保存修订后，由后台任务投递草稿，保留执行记录。
- 对不确定的远程结果保留人工核对入口，避免盲目重试造成重复草稿；正式发表在公众号后台完成。

### 部署与维护

- 公开镜像：`ghcr.io/brucewar/tattoo:0.1.0-rc.1`，支持匿名拉取，当前平台为 **`linux/amd64`**。
- 前端与 API 合并，API 和 Worker 共用一个 Tattoo 应用镜像；Compose 运行 API、Worker 与 PostgreSQL 三个容器。
- 默认部署只拉取固定版本镜像，宿主机无需 Node.js 或源码；源码构建使用单独的 Compose 覆盖文件。
- 提供随机初始配置、管理员密码恢复、升级指引、停机一致备份和空实例恢复。
- 恢复后禁用远程写入、撤销旧会话并隔离旧任务。现有备份恢复工具需要在管理电脑准备 Node.js 22 与匹配源码，详见[工具准备](OPERATIONS.md#准备备份恢复管理工具)。

### 升级与已知限制

升级前保留数据库与图片备份、原主密钥、Compose 文件和匹配镜像。从旧四服务部署升级需使用 `--remove-orphans` 清理旧 Web 容器，具体见[升级与回滚](OPERATIONS.md#升级与回滚)。数据库迁移后，仅改回旧镜像标签不保证可以回滚。

- 一个管理员、PostgreSQL 持久任务表、单 Worker；当前没有 ARM 镜像。
- 主题创作使用已配置模型，不自动搜索资料；AI 与 Tavily 调用可能产生服务费用。
- 知乎内容导出、小红书文案与图片导出尚未实现。自动选题、周期生成、热点日报与多平台自动发表未包含在此版本。
- 首版恢复只接受空目标，要求 PostgreSQL 16、精确匹配的应用镜像和原主密钥，不保证跨 CPU 架构恢复。
- 未保存的编辑不在备份中；暂不自动清理远程草稿、素材或本地未引用文件。
