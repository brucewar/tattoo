# 账户安全

[文档首页](README.md) · [开始使用](GETTING-STARTED.md) · [运行维护](OPERATIONS.md) · [常见问题](FAQ.md)

Tattoo 保留单管理员。登录后进入“账户安全”，管理密码、双重验证、恢复码和其他会话。本页适用于 `0.1.0-rc.2` 候选版本的 P14，发布状态与镜像 digest 见[版本说明](RELEASE-NOTES.md)中的标签流水线。实现与实际检查见 [P14 验证记录](P14-VERIFICATION.md)。

## 修改密码

1. 点击“修改密码”，输入当前密码。
2. 输入并确认新的 12 至 256 字符密码，使用与当前密码不同的值。
3. 已启用双重验证时，再输入验证器中的新验证码，或切换“使用恢复码”。
4. 确认成功后，当前浏览器保持登录，其他会话及未完成登录验证失效。

如果只是输入错误，修正对应字段即可，不必退出当前工作台。请求中断且结果未确认时，先刷新安全状态；密码可能已经更新，可使用新密码重新登录核对。更改部署配置中的 `ADMIN_PASSWORD` 不会覆盖现有密码。

## 启用双重验证

使用支持 TOTP 的验证器即可，包括 [Google Authenticator](https://support.google.com/accounts/answer/1066447) 与 [Microsoft Authenticator](https://support.microsoft.com/en-us/authenticator/how-to-add-your-accounts-to-microsoft-authenticator)。Tattoo 本地生成配置并验证动态码，不需要提供 Google/Microsoft 账号，也不接入它们的云登录或推送批准。

1. 在“账户安全”的“双重验证”区域点击“设置双重验证”。
2. 重新输入当前密码，点击“继续设置”。
3. 用验证器扫描二维码；微软验证器选择添加“其他账户”。也可手动录入页面显示的密钥，使用基于时间的验证码。
4. 输入验证器当前的 6 位验证码，点击“验证并启用”。扫码本身不会自动启用。
5. 成功后保存本次显示的 10 个一次性恢复码，确认“我已将这组恢复码保存到安全的地方”。

二维码、手动密钥和恢复码都属于敏感凭据，只在自己的设备和实例中操作。未确认的绑定可以取消，过期后不能继续启用；重新开始设置会替换旧二维码。

## 使用验证码登录

先输入管理员邮箱和密码，再输入动态验证码。仅通过密码、停留在第二步时，尚未取得完整登录会话。验证请求过期时点击“返回密码登录”重新开始。

每组动态码通常每 30 秒更新，**成功使用过的一组不能再次使用**。刚绑定、登录、改密或执行其他安全操作后，需要下一次验证时先等验证器更新。连续输入错误会受到挑战次数和账户级限错保护；提示锁定后等待五分钟再试，反复提交不会让验证码通过。若一直失败，检查手机与 NAS 的时间是否自动同步。

工作台会话过期时，重新登录窗口也支持验证码或恢复码。未保存的文章仍保留在当前页面，完成登录后可继续保存；不要为重新登录而刷新仍有未保存内容的页面。

## 保存与使用恢复码

启用双重验证或重新生成时，一次展示 10 个恢复码。使用“复制恢复码”或“下载恢复码”保存到安全位置；浏览器不允许自动复制时可手动选中复制。页面只在本次结果显示明文，之后不能从状态查询重新查看。

验证器不可用时，在登录第二步点击“使用恢复码”，输入一个尚未使用的完整恢复码。空格和连字符可以保留。每个恢复码使用一次即失效，也可作为账户安全操作的第二个验证因素。

“账户安全”显示剩余数量。需要更换或即将用完时，点击“重新生成恢复码”，重新验证密码和因子；**新的一组生成后，所有旧码立即失效**，需要保存新码。若生成响应丢失，旧码可能已经失效；先刷新安全状态，再用新的动态验证码明确重新生成并保存，避免反复提交当前请求。

显示新恢复码时，页面会提醒先安全保存再离开；提醒不能替代备份。把恢复码与登录密码分别保管，不把二维码、密钥或恢复码发给他人。

## 退出其他会话与更换验证器

“退出其他会话”显示其他有效会话数量，重新验证当前密码；已启用双重验证时还需要动态码或恢复码。成功后当前浏览器继续登录，其他会话需要重新认证。

更换验证器时，在账户安全中“关闭双重验证”，验证当前密码和现有因子；成功后旧因子、恢复码、其他会话及未完成登录验证失效。随后重新设置双重验证并保存新恢复码。关闭和重新绑定之间，账户使用密码登录。

## DDNS 与外网访问

从外网访问时使用 HTTPS。DDNS 负责域名解析，仍需由自己的反向代理和证书提供 HTTPS；2FA 不能代替传输加密。`APP_ORIGIN` 与浏览器实际协议、域名和端口保持一致，HTTPS 配置启用 Secure Cookie。设置方法见[局域网与 HTTPS](OPERATIONS.md#局域网与-https)。

## 备份恢复后的登录

恢复要求原加密主密钥与匹配应用版本。已启用的验证器仍然有效，但恢复会撤销旧会话、未完成登录验证、待绑定设置及全部旧恢复码，避免旧快照复活一次性凭据。

恢复后先等待当前动态码更新，再用密码和验证器登录。仍提示验证码已用时等下一组并检查两端时间。进入“账户安全”后，恢复码数量为 0，需要等待新的验证码，重新生成并安全保存一组。不会从旧备份再次显示原恢复码。

备份、空实例恢复、旧 Worker 停止及收费任务核对仍按[运行维护](OPERATIONS.md#恢复到空实例)执行；本页不替代这些步骤。

## 丢失验证器和恢复码

有未使用恢复码时，先用恢复码登录，再关闭并重新绑定验证器。仅忘记密码且仍有验证器时，使用[管理员密码恢复](OPERATIONS.md#管理员密码恢复)；普通部署重置密码保留已启用的双重验证。

验证器和恢复码均不可用时，需要有部署管理权限的人明确执行应急重置，同时设置新密码并移除 2FA。此操作撤销全部旧会话、登录挑战和恢复码；完成后使用新密码登录，重新绑定验证器并保存新码。不能通过修改 `.env` 或删除数据卷代替恢复。

### 群晖 Container Manager 终端

不需要 SSH。在 Container Manager 打开 Tattoo 的 API 应用容器终端（Compose 服务名为 `api`），启动 `/bin/bash`。镜像内已包含 Node.js 和恢复脚本，终端工作目录应为 `/app`。

先执行下面一行，在提示后输入新密码并回车；输入不显示在屏幕上：

```bash
read -r -s -p '新管理员密码: ' TATTOO_NEW_PASSWORD
```

输入完成后，再执行普通密码重置：

```bash
printf '\n'
export TATTOO_NEW_PASSWORD
node scripts/reset-admin.mjs
unset TATTOO_NEW_PASSWORD
```

普通重置保留已启用的验证器。若确实丢失验证器和全部恢复码，完成前面的隐藏密码输入后，改用下面的应急命令：

```bash
printf '\n'
export TATTOO_NEW_PASSWORD
TATTOO_RESET_2FA=true node scripts/reset-admin.mjs
unset TATTOO_NEW_PASSWORD
```

新密码通过临时环境变量传给工具，命令本身不包含密码值；不要把实际密码直接写在命令中。工具只接受明确的 `true` 或 `false` 标志，操作结束后清除临时密码变量并关闭终端。其他 Docker 管理界面也可在 API 容器中执行同一操作；管理电脑上的 Compose 操作见[管理员密码恢复](OPERATIONS.md#管理员密码恢复)。
