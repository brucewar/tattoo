## 当前已执行范围

全量单元测试 **289 / 289** 通过；全量真实 PostgreSQL/API 集成 **113 / 113** 通过，共 10 个文件，其中账户安全 **19 / 19**。数据库为本轮隔离运行的原生 PostgreSQL 16.16，监听环回地址；此结果不依赖 Docker 守护进程，也不能代替 Docker 部署验收。

账户安全测试使用专用测试库中的随机 schema、实际编译 API、测试凭据和系统分配端口，不启动 Worker、不调用真实外部接口；结束后清理自有 API、schema 和临时素材目录。API 设置 `TEST_BIND_LOOPBACK=true`，该选项仅允许 `NODE_ENV=test`，部署默认监听方式不变。

[账户安全集成测试](../tests/integration/account-security.test.ts) 覆盖密码/第二阶段、挑战限次/到期/取消、TOTP 与恢复码一次性、并发消费、会话轮换及撤销、真实不同环回源 IP 和重启后的账户锁定、普通/明确应急部署重置，以及非法应急标志无副作用。

独立数据库恢复检查在真实 PostgreSQL 执行备份工具导出的 `restoredTasksSql`：保留已启用 TOTP 的用户绑定密文，推进版本与防重放时间步，清除旧会话、挑战、待绑定、恢复码和失败计数，并在重启 API 后确认旧凭据失效、密码登录仍要求第二步。后续已实际执行包含归档、`pg_restore`、素材恢复的[完整 Docker 恢复脚本](../scripts/verify-recovery.mjs)，两类证据分别记录。

TOTP 标准向量、二维码参数和自动测试属于标准兼容证据。Google/Microsoft 真实手机 App 扫码、目标 NAS 的网络/HTTPS 与实际镜像操作单独记录，未执行时不标记通过。

真实 API 的 TOTP 浏览器闭环定点检查 **1 / 1** 通过（19.1 秒）。首轮完整浏览器回归发现与旧组件加载状态、提示角色和移动导航相关的断言不兼容并超时，未计为通过。第二轮完整入口执行 58 项，**55 通过、3 失败**（10.2 分钟）；失败分别为 P6 协议文本同时匹配可见选项和隐藏 option、P6 窄屏模型配置导航、P9 窄屏资料导航的旧选择器。三处已修正为等价的组件交互断言，未修改生产行为。

随后通过正式 API/Worker 入口复跑 P2/P6/P9 三个文件，**13 / 13 通过**（2.8 分钟，退出码 0），覆盖三个修正项并保留原有业务调用计数检查。固定测试草稿仍只创建一次，没有发表或群发调用；测试结束后已清理自有 API、Worker、Vite、schema 和临时素材目录。58 个独立用例通过整轮与修正后的定点复跑覆盖验证，不表示单次 58 / 58。

第二轮中的账户安全 13 项离线浏览器检查和 1 项真实 TOTP 流程均已通过。离线检查与真实 API 流程分别记录，不把模拟接口当作真实外部服务验收。

## 本地 Docker 生产镜像与恢复

本轮使用 Docker 29.9.3、Compose 5.7.1 和 `linux/amd64`。生产 `application` target 构建为 `tattoo-app:p14-validation`，退出码 0；这一本地测试标签不表示 GHCR 已发布。

- `node scripts/verify-foundation.mjs` 退出码 0：旧 Web 端口接管、三服务健康且 API/Worker 使用同一镜像、仅 API 发布环回端口、缺少主密钥或迁移失败拒绝启动、重复 Worker 拒绝执行、容器重建后数据保留。
- `npm run verify:recovery` 退出码 0：实际 `pg_dump`/`pg_restore` 与素材恢复、TOTP 保留及防重放时间步推进、旧会话/挑战/恢复码/待绑定清理、旧任务冻结、错误备份和非空目标覆盖拒绝，以及重建后的读回验证。
- 测试在本轮隔离项目中使用临时配置和合成凭据，结束后已清理自有容器、卷与临时目录；既有预览容器和旧 smoke 卷保留。之后重新执行全量单元，289 / 289 通过。

生产镜像实际 UI 的额外浏览器检查已通过：真实账户安全闭环 **1 / 1**（24.3 秒），覆盖 TOTP 绑定、重放返回 400、恢复码登录及剩余数量扣减、关闭 2FA 与 Cookie 轮换。浅色、深色、跟随系统、系统变化和刷新记忆通过；实际 Manrope 字体 ready、字体响应 200，CSP 违规、字体失败、JavaScript 错误和外部请求均为 0。此项是生产构建 UI 检查，独立于上文开发前端的 19.1 秒定点结果。

额外 UI 测试结束后，自有项目容器与卷均为 0、临时目录已删除，原预览三容器 ID 保持不变。真实 Google/Microsoft 手机扫码与远程 GHCR 发布结果继续单列。
