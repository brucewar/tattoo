## 字段和图像规则

| 项目            | 官方页面给出的边界                | 应用执行口径                                                       |
| --------------- | --------------------------------- | ------------------------------------------------------------------ |
| 标题            | 最多 32 个字                      | UTF-16 单位数 ≤ 32，必填                                           |
| 作者            | 最多 16 个字                      | UTF-16 单位数 ≤ 16，可空                                           |
| 摘要            | 最多 120 个字                     | UTF-16 单位数 ≤ 120，可空                                          |
| 最终 HTML       | 字符数少于 20000，大小小于 1M     | UTF-16 单位数 < 20000，UTF-8 字节数 < 1,000,000，两者都满足        |
| 原文 URL        | 不超过 1 kb                       | 安全 HTTP/HTTPS，UTF-8 字节数 ≤ 1,000                              |
| news 封面       | 使用永久素材 ID                   | 上传永久图片，不能用正文图 URL 替代                                |
| 永久 image 图片 | 10M，可用多种图片格式             | 本应用仅接受规范化 JPG/PNG；独立封面副本最多 512 KiB，低于平台边界 |
| 正文图片        | JPG/PNG，小于 1MB，来自 uploadimg | 独立上传副本严格小于 1,000,000 字节                                |

官方原文未精确定义补充 Unicode 字符如何计数，也未细分 M/MB/kb 的进制。本应用明确采用保守口径：JavaScript `String.length` 的 UTF-16 单位数不少于 Unicode 码点数，字节单位使用十进制值。这是应用的保守策略，不声称它就是微信内部精确计量。内容不会被截断；补充字符、中文与字节边界均有测试。

永久素材文档另列的 thumb 缩略图 64KB 不是本项目 news 封面的上传类型；封面以 image 永久素材处理。正文图接口不占用永久图片素材库计数，封面与正文的远程映射分别保存。

正文图响应只接受官方示例所示的 `mmbiz.qpic.cn` 精确域名，允许 HTTP/HTTPS（官方示例含 HTTP），拒绝凭据、额外端口、片段和危险格式。不从该 URL 下载图片。普通文章的每个本地图片引用都必须有已校验的微信地址；最终请求不能退回受保护的本地素材路径。

## 检查、排版与上传

- 本地保存继续使用结构与安全校验，空正文、缺封面或平台字段超限不妨碍保存。
- 预览和投递预检共享纯微信检查函数；普通文章提交同时核对账号与明确的已保存修订。
- Worker 为封面和正文图生成独立上传副本，原素材不被覆盖。
- 替换微信图片地址后，重新检查最终 HTML 的字符和 UTF-8 字节大小；不能仅验证替换前的预览。
- 原文链接进入 `content_source_url`；正文安全外链按固定排版显示文字与 URL。
- 请求体包含标题、作者、摘要、来源、封面永久 ID 和最终正文；首版仅新增一篇普通图文，不调用发表或群发。

## token、权限和结果处理

稳定 token 使用普通 POST 请求，`force_refresh:false`；官方返回的剩余有效期不超过 7200 秒。token 在数据库中加密保存，缓存按凭证版本更新，过期只清理匹配缓存，不自动重发新增草稿。

账号操作持有独立数据库会话的账号锁，凭证轮换、只读验证与 Worker 操作互斥。token 成功或草稿计数成功仍不能证明新增草稿写权限。官方页面的账号类型说明也不替代具体账号权限与白名单验证。

错误只显示安全说明、错误码和操作建议；40164 仅提取有效出口 IP，不回显含密钥或 token 的原始响应。单次请求最多 30 秒，且不超过后台任务剩余时间；响应体最多 1 MiB。

新增草稿提交中的连接中断、HTTP 失败、损坏响应、缺失远程标识和未知平台错误继续按不确定结果处理；明确拒绝才进入确定失败。人工核对、重试和旧 Worker 隔离仍执行原有规则。图片上传结果丢失可能留下远程孤立素材，首版不自动清理。
