## 当前应用自己的限制

- 本地上传：单文件不超过 10 MiB，真实 JPG/PNG，解码不超过 2000 万像素，图像处理超时 10 秒。
- 测试封面：生成独立 JPEG 上传副本，压缩到最多 512 KiB。本地规范化原素材不被覆盖。此数值是应用诊断上限，不能解释为已核实的微信素材上限。
- 外部 HTTP：30 秒截止时间，响应体最多 1 MiB，拒绝重定向；生产地址固定为官方域名。
- 正文标题、作者、摘要及 HTML 的官方数值/字符与字节计量仍待核验，未套用脚手架的旧常数。P2 仅提交固定且很短的测试稿件，不宣称任意文章兼容性通过。

## 凭据与结果处理

账号操作使用独立数据库会话的账号锁，密钥轮换、只读验证与 Worker 远程操作互斥。token 在数据库中加密缓存，按凭证版本更新；显式过期错误会使匹配缓存失效，但不会自动重发新增草稿请求。

只读验证只获得 token 与草稿总数，不能据此标记新增草稿能力通过。网络错误不等同于接口未授权。错误显示静态说明、错误码和修复建议；40164 仅提取有效 IP 地址，不回显包含 token 或 AppSecret 的原始错误文本。

新增草稿中的请求中断、HTTP 失败、无法解析响应、缺少 `media_id`，以及通用/未知平台错误均视为可能已写入，需要人工核对。仅已知的明确拒绝错误按确定失败处理；不进行自动新增草稿重试。真实账号的测试草稿必须由用户在自己的部署环境显式创建，并在微信后台确认。
