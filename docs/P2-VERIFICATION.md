# P2 本地功能与模拟接入验证

日期：2026-11-20（Asia/Shanghai）。依据：SPEC v0.2、PLAN P2。

## 结果与边界

P2 的本地功能、模拟微信链路和浏览器操作已实现并验证。用户真实公众号未参与本轮测试，真实微信验收未执行。官方文档经网页工具与浏览器补充尝试仍无法读取，现行字段计量、图像限额及目标账号权限保持待核验，详见 [微信依据](WECHAT-API.md)。本轮不将 P2 标为全部真实接入验收完成。

## 已实现功能

- 单管理员部署初始化，重复启动保留原密码；数据库会话、退出与过期、HttpOnly/SameSite Cookie、登录限流、CSRF、统一安全错误。
- 部署侧密码重置与所有旧会话撤销，密码通过临时环境变量输入，不进入命令行参数或日志。
- 多公众号配置、AppID 唯一且不可修改、AppSecret/token 加密、凭证版本与账号会话锁、轮换后缓存和验证状态失效。
- 只读 token/草稿计数验证；读取、新增草稿及 token 获取分别判断权限，不用一个接口的结果推断另一个接口权限。
- JPG/PNG 真实解码、重编码、方向修正、元数据去除、哈希去重与受保护读取；微信封面副本独立压缩。
- 固定测试文章、不可变修订、持久 Delivery、单 Worker、账号互斥、上传封面、持久化危险提交标记、单次新增草稿和执行记录。
- 重复请求去重；同请求标识改变封面报冲突；已知失败显式重试；不确定结果人工核对，要求全局 Worker 与账号执行权均释放。人工确认不能冒充接口成功或提升接口能力。
- 登录、账号设置、测试草稿、投递详情和窄屏界面，凭证不放入浏览器持久存储。

## 回归修复与环境处理

1. 同请求标识改封面：旧构建实际返回 201，回归断言要求 409。修复后真实 HTTP 用例通过。
2. 旧账号操作仍持锁：全局 Worker 锁已释放时，旧构建仍允许人工解除不确定状态。已复现 201/409 差异；修复为同时取得账号锁，回归用例通过。
3. workspace 启动的配置目录：dotenv 和素材目录统一以仓库根目录解析，避免从 `apps/server` 启动时遗漏 `.env` 或写入另一份素材目录。
4. 权限证据归属：token 获取失败不能把草稿读取/写入标成无权限，新增适配器单元测试验证实际调用接口的证据归属。
5. Windows CLI 冷启动曾超过默认 5 秒，完整集成运行其余 26 项通过，该用例超时。对密码重置子进程设置 20 秒截止、单用例 30 秒时限后，身份集成文件 5/5 复测通过；密码校验和会话撤销断言保留。未放宽其他用例时限。

本轮浏览器进程、API/Worker、临时 schema 与临时素材已清理；部署验证结束后测试容器停止，隔离持久卷按 P1 验证约定保留。GitHub Actions 已增加浏览器步骤，远端执行结果以 Actions 实际记录为准，不将本地检查等同于远端 CI 通过。
